# ADR-5. Роли и доступ

- **Статус:** принято
- **Дата:** перенесено из README 2026-09-11 (решение принято раньше)

Врач видит только свои записи и свои выплаты, может вводить, править,
удалять. Медсестра входит в систему (логин/пароль) и видит только те
анестезии, где она указана как сестра — только просмотр, без ввода
и правки (источник записи один — врач, иначе дубли). Заведующий видит
только свои анестезии; прежняя формулировка «видит всех, включая разноску файлов
и экспорт» **отменена** ADR-0023 (11.09.2026) — обзор поданных анестезий даёт
раздел «Распределение» (ADR-0024). Пароли — только хеш.

Старшая сестра — отдельная роль `head_nurse` (ADR-11): права медсестры плюс
управление разделом «Потребности»; к финансовой разноске и админке
«Компендиума» доступа не имеет.

# ADR-10. Раздел «Компендиум»: LLM-wiki по курируемым статьям

- **Статус:** принято
- **Дата:** перенесено из README 2026-09-11 (решение принято раньше)

На месте RAG-консультанта `/orders` (ADR-9) — раздел «Компендиум»
(`/compendium`): вопрос-ответ по курируемой базе знаний отделения. Вместо
чанкинга PDF по 600 симв. — двухуровневая модель «источник правды + выжимка».

- **Источник правды** — загруженный PDF (приказ, инструкция, скан). Файл лежит
  в `data/wiki/sources` с именем по хешу содержимого (в имени не остаётся ФИО),
  в БД — метаданные и имя файла (ADR-0020). Для
  сканов без текстового слоя — OCR через vision-модель (текст + таблицы).
- **Курируемые .md-статьи** — тщательно отобранные тезисы (по анестезиологии),
  связанные с источником. Версии + статус черновик/опубликовано: в ответах
  участвуют только опубликованные.
- **Поиск** — BM25 по секциям опубликованных статей (заголовок важнее тела),
  без эмбеддингов. Цитата `[1]` ведёт на статью, статья — на PDF-источник.
- **LLM и vision — RouterAI** (https://routerai.ru/api/v1): один ключ
  `AI_API_KEY`, модели ответов и OCR настраиваются env-переменными.
- **Изоляция**: код в `src/docapp/ai/` (общий ИИ-слой) и `src/docapp/wiki/`,
  данные — таблицы `wiki_*` в общей БД (`data/docapp.db`), PDF-источники —
  файлами в `data/wiki/sources` (ADR-0020).
- **Роль `editor`**: заведующий (`head`) и редактор (`editor`) курируют —
  загружают PDF и правят/публикуют статьи; настройки — только `head`.

Изменение доступа (ADR-11): медсёстры (`nurse`) к разделу не допускаются (403,
пункт меню скрыт) — для врачей, старшей сестры, редактора и заведующего.

## Обновление 12.09.2026: имя и доступ

- **Видимое имя — «Чат»** (было «Компендиум»). Модуль в коде (`wiki`), таблицы
  (`wiki_*`), адрес (`/compendium`) и имена файлов фронта не менялись: это кодовое
  имя, см. `docs/глоссарий.md`.
- **Доступ сужен до заведующего и редактора**: право `wiki.read` снято у врача,
  медсестры и старшей сестры. Решение ADR-11 в части «старшей сестре открыто»
  отменено. Раздел выпускается остальным после доработки, возврат — одна строка в
  таблице прав (`core/access.py`).
- Проверки этого поведения: `tests/test_access.py`, `tests/test_web.py`,
  `tests/test_wiki_api.py`, `tests/test_needs_e2e.py`.

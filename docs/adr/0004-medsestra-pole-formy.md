# ADR-4. Медсестра — поле формы, выбор запоминается

- **Статус:** принято
- **Дата:** перенесено из README 2026-09-11 (решение принято раньше)

Врач выбирает медсестру в самой форме анестезии. Выбор сохраняется сразу
по клику в поле (без кнопки) и запоминается: при следующем входе селектор
предвыбран тем же значением. Каждая запись фиксирует ту медсестру, что
выбрана в момент добавления. Отдельной сущности «бригада» нет.

## Уточнения

- **2026-09-11.** Поле выбора получило фильтр по набираемому тексту: тот же
  `select` остаётся в форме и отправляет то же значение, но на странице он
  скрыт, а над ним строится поле с поиском (`dc.combobox` из общей библиотеки
  `web/static/lib/core.js`). Сценарий «выбор запоминается сразу» не изменился:
  выбор строки шлёт обычное событие `change`. Без JS остаётся нативный список.
- **2026-09-11.** В списке — сестринский состав: медсёстры (`nurse`) и старшие
  сёстры (`head_nurse`). Старшая сестра тоже работает в смене, поэтому врач
  может записать её в пару. Права ролей это не меняет — расширен только
  справочный список (`people.list_nurse_staff`), решение владельца.

# ADR-7. Сервер — VPS в России

- **Статус:** принято
- **Дата:** перенесено из README 2026-09-11 (решение принято раньше)

Больничная сеть закрыта, приложение живёт в интернете и доступно с личных
телефонов. Российский VPS: 24/7, доступ отовсюду, 152-ФЗ без вопросов
трансграничной передачи. Приложение не привязано к конкретному хостингу —
миграция возможна в любой момент.

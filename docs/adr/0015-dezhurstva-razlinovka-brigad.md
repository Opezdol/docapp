# ADR-15. Раздел «Дежурства»: разлиновка дежурных бригад

- **Статус:** принято
- **Дата:** перенесено из README 2026-09-11 (решение принято раньше)

Утренняя фиксация операций ночного дежурства (16:00–08:00) и выгрузка
разлиновки по дежурным бригадам в Excel. Врач вносит операции (операция +
время начала/конца, шаг 10 минут) за свою смену; заведующий видит все
отчёты и выгружает разлиновку.

- **Окно смены**: вкладка доступна только 16:00 → 09:30 следующего дня;
  дата смены определяется автоматически (дата, когда было 16:00). До 16:00
  вкладка закрыта.
- **Статусы**: черновик (draft) → отправлен (sent) → закрыт (closed).
  Отправленный отчёт остаётся доступным для правки до закрытия; «Закрыть»
  (один отчёт или вся смена) выполняет заведующий, либо окно 09:30 закрывает
  всё автоматически (лениво, при первом обращении — без планировщика).
  Операции при закрытии сохраняются; ошибочно закрытый отчёт можно переоткрыть.
- **Роли**: врач вносит/отправляет свои, заведующий видит все, закрывает
  отчёты/смены и выгружает; медсёстры, старшая сестра и редактор доступа
  не имеют.
- **Изоляция**: пакет `src/docapp/duty/`, свои таблицы `duty_*` в общей БД.
- **Разлиновка (.xlsx)**: лист на дату, сетка «время × врач» (часы 16…8,
  шаг 15 минут), секции по базам; операция — полоска от начала до конца.
  В выгрузку попадают только закрытые (closed) отчёты.

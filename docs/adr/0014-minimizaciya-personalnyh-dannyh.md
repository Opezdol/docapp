# ADR-14. Минимизация персональных данных (152-ФЗ)

- **Статус:** принято
- **Дата:** перенесено из README 2026-09-11 (решение принято раньше)

Сознательный отказ от хранения лишнего: номер истории болезни не хранится
вовсе (миграция схемы v2 стирает и колонку, и старые значения), дата
процедуры заменена датой подачи сведений. Шифрование самой SQLite-БД
сознательно не применяется: при ключе на том же сервере оно защищает только
от кражи диска/бэкапа, но не от уязвимостей самого приложения, а SQLCipher
на shared-хостинге непропорционально сложен. Риск снижается минимизацией
данных, контролем доступа по ролям и HTTPS-only, а не шифрованием файла.
